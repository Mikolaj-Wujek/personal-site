port scanner

repo link

this program is a port scanner, which checks for open ports on a device. it tries to connect to ports on the device, determining whether it's open. it waits for one second before timing out and moving to the next port (a closed port usually refuses straight away, so the full second is for cases where there is no response at all, like a firewall dropping the connection request).

this would take a very long time if you are scanning a large range of ports, so the program allows you to pick a number of threads to use. the program then creates a worker for every thread, which pulls ports from the queue and scans them.

the program currently only finds open ports, but i would like to adapt it so that it grabs the banner from whatever is running on that port to work out what service it is. most ports are conventionally predefined to listen to a certain type of connection, so the program could check for that first.

the last thing i did was start a custom repl for it, then abandoned it halfway, so the repl is broken but the scanner itself still works.
